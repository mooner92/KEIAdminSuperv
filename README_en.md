## Why this exists

- **It must not make things up.** In admin/accounting/audit work a wrong amount or deadline is a real incident. If the source doesn't say it, the bot says "not confirmed in the regulations."
- **Every answer cites its article.** Answers end with `[Regulation, Article N]`; the evidence panel shows the exact source chunks the model read.
- **Deleted articles are demoted, broken tables are never quoted for numbers** — deterministic trust gates (numeric gate, table-integrity guard, scope anchor) attach warnings instead of relying on the LLM's good behavior.
- **Nothing leaves the building.** LLM, embeddings, reranker and vector DB all run on in-house GPUs; both screens sit behind Cloudflare Zero Trust.
- **It grades itself daily** and reports the numbers (quality board + Slack digest).

## What it is

One markdown vault (the single source of truth) served through two faces of one Next.js 14 app:

| Face | For | What it does |
|---|---|---|
| **[Brain]** browse/graph | anyone exploring | node/link graph, full-text search, document drawer with article anchors |
| **[LLM]** chat | admin beginners | RAG chat with login, persisted multi-turn history, per-message evidence, SSE streaming |

| Fact | Value (measured 2026-07-31, v1.9.0) |
|---|---|
| Corpus | **599 documents** (regulations · work guides · 307+ glossary terms · internal systems · external-affairs stats · national statutes as reference) |
| Index | **6,044 chunks** (`kei_regs`, KURE-v1) + 4,116 statute chunks (`kei_uplaw`, physically separated) |
| Models | isolated Ollama v0.31.1 — Qwen3.5-9B GGUF Q4_K_M · embeddings KURE-v1 · reranker bge-reranker-v2-m3 — all on 2× Quadro RTX 6000 (24GB) |
| Ops | daily self-evaluation (60 questions, retry/new cohorts) · Slack alert bot (8-alert catalog, leak-scrubbing backstop) · feature flags with admin toggles |

## Quickstart

Everything runs on one machine; no external APIs anywhere in the serving path.

### 1) Pipeline (tools/)

```bash
python -m venv tools/.venv && . tools/.venv/bin/activate
pip install -r tools/requirements.txt

# 01  HWP/HWPX regulations → markdown vault (article-preserving, no paraphrase)
# 01b/e/g  cross-links (regulation↔regulation, ERP↔regulation, term↔ERP) → graph edges
# 01i~01n  article refinement: citation graph, defined terms, deleted-article status,
#          deadlines, approval matrix → tools/index/*.json (no re-embedding needed)
# 01p/q/s  attached forms: HWP→ODT(font/leading fix)→PDF, per-form split + preview
# 02  chunking (1 article = 1 chunk; headings for guides) + KURE-v1 embeddings → Chroma
# 03  retrieval smoke test (no LLM needed)
# 04  OpenAI-compatible RAG API + auth/chat API (FastAPI, 127.0.0.1:9000, PM2)
python tools/01_hwp_to_md.py --src <hwp-dir> --vault KEI-행정가이드
python tools/02_chunk_and_embed.py --vault KEI-행정가이드 --db tools/chroma
python tools/03_rag_query.py --db tools/chroma --q "출장 여비 정산은 어떻게 하나요?"
```

> Requires the isolated Ollama v0.31.1 at `127.0.0.1:11436/v1` (model pulled via `hf.co/` prefix; the registry is blocked). The shared Ollama (11434) does not support the qwen3.5 architecture.

### 2) Web app (web/)

```bash
cd web
npm install
# ⚠ MUST build with Node 22 (nvm) — node 18 silently fails to emit out/docdata/*.json
NEXT_PUBLIC_BUILD_ID=$(git rev-parse --short HEAD) VAULT_DIR=../KEI-행정가이드 npm run build
```

Static export (`out/`) served by `server.js` — a zero-dependency Node server with a **built-in login gate** (JWT `kei_session`; anonymous users get the landing shell only, all content fails closed). ⛔ Never serve with plain nginx — the gate would vanish.

### 3) Serving (PM2)

```bash
pm2 start tools/ecosystem.config.js       # kei-rag-api → 127.0.0.1:9000 (local only)
pm2 start web/server.js --name kei-guide  # 0.0.0.0:3100 behind Cloudflare Zero Trust
```

## Operations

- **Search**: dense top-20 (KURE-v1) → on-prem reranker (bge-reranker-v2-m3) → top-5, with lexical-trap guards; definition-question routing; multi-turn query condensation with a rewrite-hygiene guard.
- **Trust gates** (all deterministic, all attach warnings rather than trusting the LLM): numeric gate · broken-table guard · scope anchor · deleted-article demotion · system attribution.
- **Two servers, one box**: prod (3100/9000, `main`, v1.9.0) + dev (3101/9001, `dev` worktree). Dev is the only evaluator; prod mirrors published quality data. Promotion = merge → tag → data rsync → rebuild → PM2 delete+start → **mandatory back-merge** `main → dev`.
- **Daily self-evaluation** (06:00 cron): generate 60 questions (personas × situations × tone; triple filter = deterministic defect dictionary + LLM referee), answer through the real service path, grade with retry/new **cohort split** (sample churn is ~85%/day, so only the retry cohort proves regressions), publish to the quality board, then post a **digest to Slack** with a retry-cohort drop detector.
- **Alerting** ([docs/66](docs/66-알림정책.md)): 8-alert catalog, each requiring a runbook (registration fails without one); in-app 🔔 first, Slack second; a deterministic scrubber strips regulation text, user content and emails from outgoing messages. Firewall quirk: bare `slack.com` is SNI-blocked in-house — the client pins `www.slack.com`.
- **Code graph** ([docs/67](docs/67-graphify-코드그래프.md)): graphify builds a 4k+ node knowledge graph of code + design docs (local, deterministic, zero-LLM extraction; community naming via in-house Ollama only). The refresh script includes a leak check; the graph is published to the in-app **Lab** (`/lab`, feature-flagged) with a pinned local vis-network copy (the CSP blocks CDNs by design).

## ⛔ Absolute rules (summary)

1. **Never invent regulation content** — no guessed amounts, limits, deadlines or conditions. Missing source → explicit TODO placeholder.
2. **No paraphrasing of the source layer** (`20_규정원문/`) — article structure preserved verbatim.
3. **Every guide/answer carries citations**; RAG answers keep the disclaimer.
4. Never weaken the RAG guardrail ("if it's not in the evidence, say it is not confirmed").
5. **Internal service** — no screen is ever exposed to the internet. (The regulation book itself is public via ALIO, which is why regulation-only screenshots may appear here.)

## Security / internal-only

- The public repo contains **code only**: the vault, source HWP/PDF files, DBs, indexes and secrets are gitignored (history was purged once; a pre-commit hook and a CI guard block Korean-path leaks; gitleaks scans the full history — synthetic test fixtures are allowlisted via `.gitleaksignore` under a strict "synthetic-only" rule).
- Server-side login gate (fail-closed) · CSP with no external origins · proxy body limits · rate-limit hardening · admin fail-closed (`APP_ADMINS` empty by default).
- Security regression suite: gate-bypass tests (22 cases incl. path traversal), content-guard CI, auth-hardening tests.
