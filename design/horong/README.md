# 호롱(Horong) 디자인 핸드오프 — 원본 자산

> 2026-07-24 전면 리뉴얼의 **디자인 원본**. 구현은 `web/`에 이미 반영돼 있고,
> 이 폴더는 "왜 이 값인가"를 되짚을 때 여는 **참조 자산**이다.
> 규약·원칙의 정본은 [`../../docs/design-system.md`](../../docs/design-system.md).

## ⛔ 이 폴더를 다루는 규칙

1. **시안을 페이지에 붙여넣지 않는다.** 기존 CSS Modules 구조를 유지하며 값(색→토큰 변수·radius·shadow·간격)만
   시안 값으로 맞춘다. 로직·플래그·API 코드는 손대지 않는다.
2. **시안과 코드가 어긋나면 코드가 정본이다.** 시안은 2026-07-24 시점의 스냅샷이고, 이후 결정
   (예: 그라데이션 2색 원칙)은 `docs/design-system.md`에 기록된다. 시안을 근거로 코드를 되돌리지 말 것.
3. **여기 파일을 수정하지 않는다.** 원본 스냅샷이라 손대면 "무엇이 원안이었는지"를 잃는다.
   새 결정은 `docs/design-system.md`에 추가한다.

## 반입 시 정제 내역 (2026-07-27)

공개 레포에는 규정 **내용**이 나갈 수 없다(⛔ 절대 규칙 · 코드만 공개 원칙). 시안의 더미 데이터 중
**실제 규정 값과 일치하는 것**을 확인해 다음을 치환했다. 색·간격·타이포 등 디자인 스펙은 불변.

| 원본 | 치환 | 이유 |
|---|---|---|
| `출장 종료 후 14일 이내`(8곳) | `N일 이내` | 볼트 원문에 실존하는 기한 값 |
| `1일 25,000원 정액`(6곳) · `25,000원`(4곳) | `00,000원` | 여비 별표의 실제 정액 |
| `kim@kei.re.kr`(4곳) · `name@kei.re.kr`(6곳) | `sample@example.com` · `name@example.com` | 개인 식별 가능 주소 |

`회원가입 — @kei.re.kr 인증` 문구는 **기능 설명**(가입 도메인 제한)이라 유지했다.
