# docs/41 — 메뉴 정리: '추가 기능' 허브 + 푸터 슬림화

> 발단(2026-07-15): GNB·푸터가 난잡. 사용자 제안 — 푸터의 '서식 찾기'·'새로워진 점'을 빼서
> 지금 KEI를 '추가 기능'(기타 기능)으로 개명해 그 안에 모아 잡동사니 허브로 관리하되 가독성 유지.

## 변경
- **GNB '지금 KEI' → '추가 기능'**(/now 라우트 유지). 순서: …업무 캘린더 · 추가 기능.
- **/now를 기능 허브로 재구성**(두 구역, 3+3 카드로 가독성 확보):
  - **바로가기**: 📅 업무 캘린더(이번 달 N건 프리뷰) · 📄 서식 찾기(서식 N종) · 🆕 새로워진 점(최근 노트).
    각 카드는 해당 flag(events_tab/forms_registry/changelog) on일 때만. formsCount는 loadForms 빌드타임.
  - **요즘 흐름**: 📈 인기 키워드 · 📜 최근 개정 규정 · 📖 오늘의 용어. (중복이던 새로워진 점 정보 카드 제거)
- **푸터에서 '서식 찾기'·'새로워진 점' 링크 제거** → 허브로 일원화. 푸터엔 도움말·FAQ·소개·관리자만.
  (배너의 새로워진 점 알림은 유지 — 진입은 허브·배너 양쪽)

## 검증
- verify-now 22/22(허브 제목·바로가기 3종·요즘 흐름 3종·서식 수), verify-calendar-forms 14/14,
  verify-changelog 11/11·verify-flags(둘 다 푸터→허브 바로가기 검증으로 갱신)·landing·help-hub 통과.
