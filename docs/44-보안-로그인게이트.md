# docs/44 — 서버 로그인 게이트 (secure check)

> 2026-07-16. 배경: 소개(랜딩) 페이지(`/`, `/about`)가 **외부 공개될 수 있음**.
> 기존엔 Cloudflare ZT(사내망)가 유일한 방벽 + 클라이언트 게이트(GNB 숨김)뿐이라,
> URL만 알면 비로그인으로 규정 원문(docdata·검색인덱스·문서 페이지)을 그대로 내려받을 수 있었다.

## 1. 위협 모델 (발견된 구멍)
| 구멍 | 내용 |
|---|---|
| 정적 산출물 전체 | `/browse/`·`/d/<slug>/`·`/docdata/*.json`·`/search-index.json`(4MB 전 규정 본문)·`/changelog.json`·`/approval.json` — 전부 무인증 다운로드 가능했음 |
| `/_next/data/*` | 페이지 데이터 JSON(문서 본문 포함)도 무인증 |
| `/api/rag/chat` | 업스트림 `/v1/chat/completions`(OpenAI 호환)가 **무인증** → 익명으로 RAG 질의(규정 내용 반환) 가능했음 |
| 랜딩 소개 카드 | `/about` 카드가 실제 서비스(`/browse/` 등)로 링크 — 외부 공개 시 진입점 노출 |

## 2. 구현 (web/server.js — 의존성 0 유지)
- **JWT 검증을 정적 서버에서 직접**: `app_api.py`와 동일한 HS256·쿠키 `kei_session`·`tools/.app_secret`(env `APP_SECRET_FILE`)을 Node `crypto`(HMAC + `timingSafeEqual`)로 검증. 만료(exp) 확인.
- **fail-closed**: 기본 켜짐. 세션키 파일이 없으면 전부 차단. 해제는 `REQUIRE_LOGIN=0`뿐(비상용).
- **비로그인 허용 목록(이외 전부 302 → `/`)**:
  - 페이지: `/`, `/about(/)` — 랜딩 셸
  - 자산: `/_next/static/*`(해시 코드만), `/_next/data/<id>/{index,about}.json`, `/fonts/*`, `/favicon.*`
  - API: `/api/app/auth/*`(로그인·가입), `/api/app/flags`(비민감 불리언), `/api/rag/health`
  - `/api/rag/chat` → 비로그인 **401** (업스트림이 무인증이므로 게이트는 여기)
  - `/api/app/*` 나머지 → 통과(FastAPI가 자체 JWT 인증 — 이중 게이트 불필요)
- ⛔ 허용 목록에 규정 콘텐츠(`docdata/`·`search-index` 등)를 추가하지 말 것.

## 3. 랜딩 정리
- `/about` 소개 카드 3종(규정 둘러보기·관계 그래프·서식 찾기) → **프레젠테이션 전용**(링크 제거, hover 강조 제거). 서비스 진입은 로그인으로만.
- 랜딩 자체(`/` home variant·`/about`)는 새니타이즈 목업만 포함(docs/36 §5) — 실규정 텍스트·수치 0 유지.

## 4. 검증 (`web/verify-secure.mjs`, 31/31)
- 익명: 공개 3종 200 · 콘텐츠 경로 14종 302 · `_next/data` 랜딩만 200 · `/api/rag/chat` 401
- 익명 브라우저: `/browse/` 직접 진입 → 랜딩 착지 + 규정 목록 미노출
- `/about` 카드에 서비스 링크 0건(텍스트는 유지)
- 로그인 후: 전부 200
- 기존 스위트 12종 함께 통과(익명이던 스크립트에 로그인 추가: journey/graph/drawer/explore/pages/content-search/trackC-dark + now·changelog의 flag-off 컨텍스트, flags의 /admin 게이트 판정을 리다이렉트 수용으로).

## 5. 운영 주의
- **nginx로 서빙할 경우 이 게이트가 없다** — server.js를 통해서만 서빙하거나, nginx `auth_request`로 동등 게이트를 재현해야 한다. 외부 공개 전 필수 확인.
- prod(3100, 동결)는 병합 시 게이트가 함께 들어간다. 병합 전까지 prod는 CF ZT가 유일 방벽(현행 유지).
- dev 전용 리스크(병합 시 제거): `admintest` 계정·`APP_DEV_ECHO_CODE=1`(가입 코드 응답 동봉).
- 남은 개선(후순위): 로그인 rate-limit(브루트포스), CSP(Next 인라인과 충돌로 보류 — v1 ⑮ 문서화됨).
