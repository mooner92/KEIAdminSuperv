# 26. 답변 후속 질문 제안 + 원문 선택 질문 (상업 패턴 이식, docs/17 §외부 벤치)

> 출처 패턴: Perplexity Related Questions / Adobe AI Assistant 선택 질문.
> 승인 배경: 행정은 절차 기반이라 "다음에 물을 것"이 구조적으로 존재(사용자 확인).
> 보류: 인용 검증 배지(난잡 우려)·확정 답변 캐시(수동 갱신 부담) — §3 완화안만 기록.

## 1. 답변 후속 질문 제안 (flag `followup_suggest`)

**⛔ 무LLM·결정적** — 추측 생성이 아니라 이미 확정된 인덱스에서 템플릿으로만 만든다:
- **여정 점프**: 질문/근거가 여정 제목 키워드(국내출장·연차휴가…)와 일치 → "🗺 {여정} 전체 여정 보기"
  칩(→ `/journey/?task=id`). 채팅↔여정 연동(docs/25 잔여)을 이것으로 해소.
- **후속 단계**: 근거에 ACTION_FLOWS의 from 화면(국내출장신청 등)이 있으면 → "{다음 화면}은 어떻게
  하나요?"(정산·결과보고). 문서로 확정된 쌍만.
- **기한**: 인용 규정이 deadlines.json에 기한 보유 → "제출·정산 기한은 언제까지인가요?"
- 상한 3개 · 이미 질문에 포함된 주제 제외 · **결재선은 제외**(기존 '결재선 알아볼까요?' 카드와 중복 금지).
- 배선: `rag_core.suggest_followups(question, srcs)` → 비스트림 응답·SSE `done`에 `suggestions` 동봉
  (휘발성 — 저장 안 함). 칩 클릭: ask형=입력 전송, journey형=페이지 이동.

## 2. 원문 선택 질문 (flag `select_ask`)

문서 드로어에서 구절을 드래그하면 선택 근처에 "💬 이거 물어보기" 팝오버(4~160자 한정).
- 클릭 → **입력창에 프리필만**(『선택 구절』 + "— 이게 무슨 뜻인가요?") — 자동 전송하지 않음
  (사용자가 질문을 다듬을 수 있게 + 오발사 방지).
- 채팅 화면의 드로어: 콜백으로 입력창 직접 채움. 둘러보기 등 다른 화면: `/?q=…`로 이동(프리필).
- **기능 중복 금지**(사용자 요구): 결재선 카드·표 보기 등 기존 컨텍스트 기능과 겹치지 않게
  팝오버는 '질문하기' 단일 액션만.

## 3. 보류 항목의 완화안(기록용 — 진행 안 함)

- 인용 검증: 사용자 배지 대신 **무음 텔레메트리**(미확인 인용을 관리자 대시보드에만 집계)로 가능.
- 확정 답변 캐시: 캐시에 근거 문서 슬러그를 저장하고 **원본 문서가 변경/재적재되면 자동 정지**
  (라이브 RAG 폴백 + 관리자 알림) — 수동 갱신 부담을 구조로 제거하는 방식. 필요 시 재논의.

## 4. 수용 기준
ⓐ 유닛: 제안이 인덱스 사실에서만 생성(무LLM)·상한·중복 제외 ⓑ 채팅 E2E: 칩 렌더→클릭 전송,
여정 칩→/journey 해당 여정 ⓒ 드로어 선택→팝오버→입력창 프리필(자동 전송 없음) ⓓ 플래그 게이트.
