# docs/45 — 용어 인라인 툴팁 (+ 채팅 아이콘 폴리시)

> 2026-07-16. docs/38 아이디어 풀 1순위(★★ — 신입 UX·채팅 상호작용 두 관점이 독립 수렴).
> 목표: 신입이 답변·규정 본문에서 만나는 행정 용어(품의·기안·전결…)를 **0클릭·무LLM**으로 해소.

## 1. 동작
- 본문·답변 속 용어집 등재 용어에 **점선 밑줄** → 호버/포커스/탭 시 **정의 팝오버**
  (용어명 · 정의 첫 문단 · '용어집에서 보기 →' 링크 · ⛔미검수면 **'검수 전 초안' 배지**).
- 적용 범위 = `Markdown` 컴포넌트 전체: 문서 페이지(/d) · 문서 드로어 · 그래프 패널 · **채팅 답변**
  (전부 같은 컴포넌트라 통합 지점 1곳). 드로어에선 링크가 in-place 문서 전환(onNavigate).
- 플래그 `term_tooltips`(레지스트리 기본 on · 프론트 안전기본 off) — /admin에서 즉시 회수, off면 평문.

## 2. 데이터 (무LLM·빌드타임)
- `emit-docdata.mts`가 30_용어집(88개)에서 추출 → `out/terms-tooltip.json`
  `[{t: 용어, s: slug, d: 정의(첫 실질 문단 ≤220자), r: 검수완료 여부}]`
- 정의 추출: crosslink 블록·헤딩·콜아웃·리스트 줄 제외 후 첫 문단. 링크·마크업 제거.
- 클라이언트는 런타임 1회 fetch(모듈 캐시·실패 시 영구 평문 폴백).

## 3. 매칭 규칙 (lib/terms.tsx)
- **최장 우선** 단일 정규식(88개 alternation), **시작 경계만** 요구:
  앞이 한글/영숫자면 단어 중간(예: '위임전결규정'의 '전결')이라 제외, **뒤 조사는 허용**(전결로/품의서).
- **렌더(문서)당 용어별 첫 등장만** 밑줄 — 시각 소음 방지. 렌더 패스마다 Set 초기화(결정적).
- `selfSlug`: 용어 자기 노트에서 자기 자신 밑줄 금지.
- 주입은 **React 렌더러 레벨**(Markdown p/li/td의 문자열 children 치환) — DOM 직접 조작이 아니라서
  채팅 **스트리밍 재렌더와 충돌 없음**(react-markdown 재조정 안전). `<a>`·`<code>` 내부는 비대상.

## 4. 팝오버 UI
- `position: fixed`(뷰포트 기준) — 드로어 overflow에 잘리지 않음. 아래 공간 부족 시 위로.
- 닫힘: mouseleave(180ms 유예 — 팝오버로 마우스 이동 허용)/blur/Esc/재클릭. `role="tooltip"`.
- KRDS 토큰만(테두리 border-strong·shadow-pop·radius-md). 다크 대비 실측 240.

## 5. 수용 기준 — verify-term-tooltip.mjs (13/13)
매칭 실문서 동적 탐색(search-index 기반, 스크립트 낡음 방지) → 밑줄 렌더 → 팝오버(용어명+정의
+미검수 배지) → 링크로 용어 노트 이동 → 자기 노트 제외 → flag off 평문 → 드로어 fixed 가시 → 다크.

## 6. 한계·후속
- 굵게(**용어**)·링크 안 텍스트는 비대상(문자열 children만) — 실측상 본문 용어는 대부분 평문.
- 2글자 용어(품의·기안 등 9개)는 복합어 선두에서도 매칭될 수 있음(예: '품의서'의 품의) — 관찰 후
  소음이면 per-term 예외 목록 도입.
- 용어집 자체가 자동 초안(전량 미검수) — 팝오버 배지로 고지(절대규칙 3). 검수 트랙은 review_queue.

## 7. (동반) 채팅 아이콘 폴리시 — 사용자 피드백 3건
- 컴포저 **보내기/중단 → 아이콘 전용 원형 버튼**(파란 ↑ / 빨간 링 ■, aria-label 유지).
- 텍스트 프레젠테이션으로 뭉개지거나 CSS 착색되던 글리프 교체:
  🖋→📝(결재 자문) · 📎→📚(근거 N개·FAB) · 👤→🧑(사용자 칩, 보라 착색 해소) · 🆕→✨(배너 가독성).
- 테스트 셀렉터 has-text("보내기") 19곳 → `aria-label` 기준. 스테일 3100 타깃 verify 10종 → 3101.
