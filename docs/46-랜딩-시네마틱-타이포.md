## 2. 변경 목록 (전부 CSS+카피, 구조 불변 — 섹션 6개·ScrollRail·플래그 유지)
1. **히어로**: kicker(mono 소형) → 2행 초대형 헤드라인
   `물어보면,` / `규정이 답합니다.`(← 유일 그라디언트) — clamp(52px, 8.5vw, 104px)·weight 800·자간 -0.045em·행간 1.04.
   서브리드에 기존 필수 문구 유지("모든 답변에 [규정명 제N조] **출처가 달립니다**" — verify 계약).
2. **메타 스트립**(히어로 하단, SpaceX): mono 대문자 라벨+숫자 —
   `규정 원문 {regs} · 업무 가이드 {guides} · 행정 용어 {terms} · 출처 표기 100%`(counts 실측치, 0이면 숨김).
3. **SCROLL 큐**: 히어로 맨 아래 mono `SCROLL ↓` + 은은한 바운스(reduced-motion 시 정지).
4. **넘버링 아이브로**: `01 — 질문하기` … `05 — 시작하기`(mono·tabular-nums, 액센트 색 유지).
5. **수치 나열형 헤드라인**(explore): "규정 {regs} · 가이드 {guides} · 용어 {terms} — 전부 연결돼 있습니다."
6. **타이포 스케일 상향**: 섹션 h2 clamp(32px, 4.2vw, 50px)·자간 -0.03em, 섹션 세로 패딩 96→128px(데스크톱).
7. **리빌 모션**: opacity+translateY(12px), 0.5s ease, 자식 지연 계단(60ms) — 기존 IO 훅 재사용, reduced-motion 가드 유지.
8. **ChatMockup 창 크롬 정돈**: 타이틀바에 창 제목 텍스트 + 그림자 소폭 강화.

### §2-9. 모션 이식 (2026-07-16 추가 — gomdori 실해부 결과)
대상 사이트 해부(Playwright): 라이브러리 0(GSAP·framer 없음), 순수 CSS 트랜지션 + IO 클래스 토글.
느낌의 실체는 파라미터 — 이를 이식:
- 리빌: `0.5s ease/14px` → **`0.9s cubic-bezier(0.2,0.7,0.2,1)/30px`**(빠른 출발→부드러운 안착).
- **히어로 오프닝 스태거**: kicker→h1→lead→CTA→메타→SCROLL, 0/80/170/260/350/450ms
  (요소별 `data-reveal` — 로드 시 IO 즉발이라 페이지 오프닝 연출이 된다).
- 카드 계단 0.7s/18px/70ms 간격으로 정합.
- 살아있는 디테일 3종: kicker **● 펄스 점**(`pulseDot` 2.2s box-shadow 링), 목업 답변 끝
  **깜빡이 커서**(`cursorBlink` 1s steps(1)), SCROLL **흐르는 세로선**(`cueSlide` scaleY 0→1→0,
  origin top↔bottom 전환).
- 전부 `prefers-reduced-motion: no-preference` 블록 안 — 리듀스드 모션에선 정의 자체가 없음.
  검증 ⑤를 강화: 첫 6개 리빌 요소가 op>0.5·transform none(정적 opacity 디자인 값 수용).
