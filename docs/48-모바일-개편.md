# docs/48 — 모바일 개편: 채팅·조문 중심

> 2026-07-16. 지시: "모바일은 채팅이랑 조문 위주로. 관계그래프 같은 건 모바일에서 중요도가 낮다."

## 1. 진단 (390px 실렌더)
| 화면 | 문제 |
|---|---|
| 채팅(/) | **대화 목록 사이드바가 채팅 위에 통째로 쌓여**(max-height 200px 블록) 입력창이 화면 밖 — 첫 화면에서 질문 불가 |
| 둘러보기(/browse) | **필터 체크박스 ~30개가 첫 화면 전체 차지** — 조문 목록이 한참 아래 |
| GNB | 7탭 가로 스크롤 — 좁은 화면에서 과밀 |

## 2. 설계 — 모바일 = 채팅 + 조문, 나머지는 허브로
1. **GNB 핵심 3탭**(≤640px): 질문하기 · 규정 둘러보기 · 추가 기능.
   그래프·결재선·업무 한 장·캘린더 탭은 `navSecondary`로 숨김(데스크톱 불변).
2. **도달성 보존**: '추가 기능'(/now) 허브 바로가기에 **관계 그래프·결재선(flag)·업무 한 장(flag)**
   카드 추가 — 모바일에서 빠진 화면 전부 허브 2탭 이내 도달(데스크톱에도 노출 — 허브 본래 역할).
3. **채팅(≤720px)**: 사이드바를 위에 쌓지 않고 **좌측 드로어**로 — 상단 모바일 바
   `[☰ 대화 목록] [＋ 새 대화]`, 드로어는 backdrop 탭/대화 선택 시 닫힘.
   → 빈 화면·제안 칩·입력창(아이콘 버튼)이 **첫 화면**에 들어옴.
4. **둘러보기(≤880px)**: 필터 패널 기본 접힘 — `필터 열기 ▾ (N개 적용 중)` 토글.
   검색+범위 칩+**조문 목록이 첫 화면**.
5. 그래프·여정 등은 축소·제거하지 않음(모바일 스텝퍼 등 기존 대응 유지) — 진입 경로만 허브로.
