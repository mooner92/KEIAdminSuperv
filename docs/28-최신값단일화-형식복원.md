# 28. 최신값 단일화 · 표 반영 · 형식 복원 — 실행 계획

> 사용자 지시(2026-07-13): ⓐ 옛값은 삭제 대신 **취소선 + RAG 제외**(최신값만 반영) ⓑ 표 복원
> 제안은 전부 정확함 확인 → **직접 반영** ⓒ 표 외 일반 텍스트의 변환 형식 붕괴도 **원문 대조로
> 형식만 복원**. 이 문서는 계획·규약 — 실제 값·문서 상세는 볼트 감사 보고서 참조.

## 과업 B — 표 복원 일괄 반영 (사용자 검수 승인 완료 → 선행)

1. 자동 매칭분: `_apply_restore` 로직으로 7문서 일괄 반영(파일 백업 + CorpusAudit).
2. 수동 필요분(평탄화·병합 구조): 복원 제안의 표를 볼트 md에 직접 교체 — 제안 형태 그대로
   (사용자가 "전부 맞는 표"로 승인한 대상이 곧 제안본). 교체 전 원본 백업.
3. 재색인 → P0-3 표손상 배지 자동 해제 확인 + 경조금류 질의 E2E(유보 해제·정답).

## 과업 A — 최신값 단일화 (옛값 취소선 + RAG 제외)

**표기 규약**(가치층 가이드의 낡은 서술):
```
~~옛 서술 그대로~~ <!--outdated 2026-07-13: 현행은 [[규정#조]] 기준-->
현행: (최신 값 서술) [[규정명#제N조]]
```
- 웹 뷰어: 취소선 렌더(이력 확인 가능, GFM 확인 완료). 삭제 아님 — 사용자 요구 그대로.
- **RAG 제외**: `02_chunk_and_embed.py`에 `strip_outdated()` 추가 — `~~…~~`·`<!--outdated…-->`
  구간을 임베딩 텍스트에서 제거(strip_wikilinks와 같은 지점). 재색인 후 옛값은 검색 불가.
- **구판 '문서 전체'**(승진·평가 구판, 계약기준 구판 등): 문장 단위가 아니라 **문서 단위 제외**
  (기존 코퍼스 관리 exclude — 파일 불변·복귀 가능) + 문서 머리에 "구판 — 현행은 [[신판]]" 배너.
- **ERP 화면 안내 실충돌**(업무추진비 하한): 화면 실물 확인은 사람 몫 — 노트에 "현행 규정
  기준은 [[내부감사규정#별표 1]]" 주석만 부착(값 단정 없음), 확인 후 확정.
- 적용 대상: 정합성 감사 19건(볼트 보고서) 중 가이드 낙후분 — 각 건은 감사 보고서의 원문
  인용을 근거로만 편집(새 값 창작 금지, 근거 링크 필수).
- 검증: ⓐ 편집 후 취소선 밖 본문에 옛값 잔존 스캔(결정적) ⓑ 재색인 후 인덱스에 옛값 청크
  부재 확인 ⓒ RAG E2E — 해당 질문에 최신값만 답하는지 ⓓ 골든셋 무회귀.

## 과업 C — 일반 텍스트 형식 복원 (원문 대조, 형식만)

1. **진단 스캐너**(`01t_format_scan.py`): 깨진 형식 신호 점수화 —
   비정상 문자(사설영역·한자 잔재), 무줄바꿈 초장문 단락, 목차 붕괴 패턴, 리스트 마커 인라인
   병합(가./①… 연속), 원문 대비 문단 수 비율. → 대상 문서 목록(우선순위 = 검수 큐 상단·감사 관련).
2. **복원**(⛔ LLM 미사용 — 결정적): hwpx=OWPML 문단·리스트 구조 재추출(hwp_tables 확장),
   hwp=문단 센티널 경로, PDF=PyMuPDF 블록 단위. 원본 파일은 `rule_files/`·`research_rule_files/`.
3. **내용 불변 검증기**: 교체 전후 텍스트를 정규화(공백·마커·취소선 제거)해 **완전 동일**해야만
   교체 허용 — "형식만 복원" 보장을 기계로 강제. 위반 시 그 문서는 사람 확인으로.
4. 단계: 파일럿(형식 최악 3~5문서) → 검증기·렌더 확인 → 확대. 재색인은 A·B와 묶어 최소 횟수.

## 순서·가드레일

- 순서: **B(승인 완료) → A(편집+청커+재색인 1회) → C(스캐너→파일럿→확대)**.
- ⛔ 모든 편집 전 파일 백업, 검수상태 자동 변경 없음, 원문층은 형식·취소선·주석만(의역 금지),
  볼트 변경은 git 밖(Syncthing) — 커밋은 코드·스펙만.
- 완료 후: 재색인 → 신뢰 게이트 E2E + 골든셋 + 정합성 스캐너 재실행(잔존 충돌 0 확인).
