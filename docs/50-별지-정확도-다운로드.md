# docs/50 — 별지(서식) 정확도 개선 · 원문 PDF 다운로드

> 2026-07-16. 지시: 규정집 111개 별지 전수조사, 원문 HWP를 이미지로 직접 확인해 깨진 MD 복원,
> 별지 부분만 다운로드하는 기능, 서식찾기 페이지 페이지네이션(10/30/50)·품질 점검.

## 1. 인프라 (이번에 구축)
- **LibreOffice(Writer) + H2Orestart** 설치(deploy/setup_ubuntu_hwp.sh 경로). ⚠ 사내망이
  대용량 HTTP를 차단해 openjdk deb은 HTTPS 미러(kakao)로 수동 설치, JRE는 Adoptium tar.
  H2Orestart는 `unopkg add --shared`(커스텀 LO 프로필에서도 인식되게 공유 설치 필수 — 실측).
- **`tools/01p_byeolji_pdf.py`**: 볼트 `원본파일` 프론트매터 ↔ rule_files HWP 정확 매핑 →
  HWP→PDF(캐시) → 별지 라벨 페이지 탐지 → ①별지별 분리 PDF(`web/public/forms-pdf/<규정>/…`,
  다운로드용) ②페이지 PNG 렌더(`tools/byeolji_png/`, 복원·검수용) ③manifest
  (`tools/index/byeolji_manifest.json`: 라벨·원문 서식명·페이지·경로).
  - PDF 텍스트가 라벨을 여러 줄로 쪼개는 문제('['/'별지제1'/'호서식]') → 상단 줄 압축 결합 매칭.
  - **원문 서식명 = 페이지 최대 폰트 스팬**(제목) — 서식찾기 서식명의 정답 소스.
- **`tools/01q_byeolji_audit.py`**: 볼트 MD 별지 블록 전수 감사 — A(빈)/B(구조 소실)/C(표 깨짐)/
  D(빈약)/OK 분류 + manifest 페이지수 대조(원문 N페이지 vs md 빈약 → 승격). 자동 수정 없음(리포트만).
- 산출물 전부 git-external(.gitignore: forms-pdf/·byeolji_png/·.byeolji_cache/ — 내부 콘텐츠 커밋 금지).
- 다운로드 서빙: 정적 out/forms-pdf(빌드 시 public/ 복사) — **로그인 게이트 뒤**(docs/44 허용목록 밖).

## 2. 서식찾기 페이지 개선
- **서식명 교정**: loadForms가 manifest 서식명(원문 제목)을 1순위로 조인 — '10일 이내'·'주소' 같은
  깨진 md 휴리스틱 제목을 원문 기준으로 교체(휴리스틱은 폴백 유지).
- **원문 서식(PDF) 다운로드 컬럼**: 별지별 분리 PDF 링크(`download`).
- **페이지네이션**: 10/30/50개씩(기본 30) + ‹ › 이동, 검색·필터 변경 시 1페이지 복귀.

## 4. MD 복원 (P4)
- 감사 A/B/C 우선, 렌더 PNG와 대조해 표/양식 복원(원문층 규칙: **깨짐·오타만 교정, 의역 금지**).
