# docs/50 — 별지(서식) 정확도 개선 · 원문 PDF 다운로드

> 2026-07-16. 지시: 규정집 111개 별지 전수조사, 원문 HWP를 이미지로 직접 확인해 깨진 MD 복원,
> 별지 부분만 다운로드하는 기능, 서식찾기 페이지 페이지네이션(10/30/50)·품질 점검.

## 1. 인프라 (이번에 구축)
- **LibreOffice(Writer) + H2Orestart** 설치(deploy/setup_ubuntu_hwp.sh 경로). ⚠ 사내망이
  대용량 HTTP를 차단해 openjdk deb은 HTTPS 미러(kakao)로 수동 설치, JRE는 Adoptium tar.
  H2Orestart는 `unopkg add --shared`(커스텀 LO 프로필에서도 인식되게 공유 설치 필수 — 실측).
- **`tools/01p_byeolji_pdf.py`**: 볼트 `원본파일` 프론트매터 ↔ rule_files HWP 정확 매핑 →
  HWP→PDF(캐시) → 별지 라벨 페이지 탐지 → ①별지별 분리 PDF(`web/public/forms-pdf/<규정>/…`,
  다운로드용) ②페이지 PNG 렌더(`tools/byeolji_png/`, 복원·검수용) ③manifest
  (`tools/index/byeolji_manifest.json`: 라벨·원문 서식명·페이지·경로).
  - PDF 텍스트가 라벨을 여러 줄로 쪼개는 문제('['/'별지제1'/'호서식]') → 상단 줄 압축 결합 매칭.
  - **원문 서식명 = 페이지 최대 폰트 스팬**(제목) — 서식찾기 서식명의 정답 소스.
- **`tools/01q_byeolji_audit.py`**: 볼트 MD 별지 블록 전수 감사 — A(빈)/B(구조 소실)/C(표 깨짐)/
  D(빈약)/OK 분류 + manifest 페이지수 대조(원문 N페이지 vs md 빈약 → 승격). 자동 수정 없음(리포트만).
- 산출물 전부 git-external(.gitignore: forms-pdf/·byeolji_png/·.byeolji_cache/ — 내부 콘텐츠 커밋 금지).
- 다운로드 서빙: 정적 out/forms-pdf(빌드 시 public/ 복사) — **로그인 게이트 뒤**(docs/44 허용목록 밖).

## 2. 서식찾기 페이지 개선
- **서식명 교정**: loadForms가 manifest 서식명(원문 제목)을 1순위로 조인 — '10일 이내'·'주소' 같은
  깨진 md 휴리스틱 제목을 원문 기준으로 교체(휴리스틱은 폴백 유지).
- **원문 서식(PDF) 다운로드 컬럼**: 별지별 분리 PDF 링크(`download`).
- **페이지네이션**: 10/30/50개씩(기본 30) + ‹ › 이동, 검색·필터 변경 시 1페이지 복귀.

## 6. 운영 연동 (같은 날 구현 — 사용자 지적 반영)
1. **재색인 연동**: `/app/corpus/reindex`가 02 전에 **01p를 증분 실행**(HWP mtime 캐시 +
   per-규정 manifest 재사용 — 무변경 시 ~8초). 규정 업데이트 → 재색인만 해도 별지 PDF·
   manifest가 함께 갱신된다. 실패해도 재색인은 계속(부가 산출물).
2. **직결 서빙**: server.js가 `/forms-pdf/*`를 `web/public`에서 우선 서빙 — **웹 재빌드 없이**
   01p 산출물이 즉시 반영(out/은 빌드 시점 사본). 게이트 통과 후에만.
3. **⛔ 복원본 보호**: 01_hwp_to_md 재실행이 비전 복원 별지를 깨진 변환본으로 되돌리는 사고 방지 —
   `byeolji-restored` 마커가 있는 md는 건너뜀(강제는 `--overwrite-restored`).
4. **누락 별지 감지**: 01q가 manifest↔md 라벨 diff(`missing_in_md`) 리포트.

### 추가 확인 필요(후속)
- 관리자 규정 업로드(corpus/upload) 저장 경로가 rule_files와 별개면 01p `--src` 통합 필요.
- 라벨 없는 '별지'(generic)·서식명 40자 절단 — manifest 조인 실패분 스팟체크.
- 분리 PDF 경계(다음 별지 라벨 미탐지 시 범위 과대) 표본 검수.
- 매핑 실패 28건 목록: `byeolji-run.log` — 비HWP 소스 규정의 원문 확보 여부 결정.

## 4. MD 복원 (P4 — 2026-07-16 실행 결과)
- 워크플로 fan-out(48개 규정 파일 × 1에이전트, 190블록 계획): 원문 PNG 대조 전사 —
  **138건 복원**, 스킵 52건 전부 정당(원문 자체가 '삭제된 서식' 26건+ = 감사 오탐,
  PNG 없음 13건 = 지어내기 거부, 기타 검증불가 보류). 에이전트 실패 0.
- 감사 지표: 복원 우선 **214 → 46건** (A 28→0 · B 6 · C 40). 잔여 46건 대부분
  원본 HWP 미보유 6개 규정(공무 항공마일리지·기본연구사업 배분기준·상조회규약 등) —
  원문 확보 후 같은 파이프라인 재실행으로 처리 가능.
- 01q 개선(복원 중 발견): 라벨 줄 '삭제 <YYYY…>' = 폐지 서식 OK 처리 ·
  `byeolji-restored` 마커 블록 OK(검수 대기) + 페이지수 승격 제외.
- 표본 검수: 인사규정 별지 제1호(신규임용계약서) — 제목·조문·근로시간 표(휴게 12~13시)
  원문 PNG와 일치 확인. 복원 블록엔 전부 마커 + `검수상태: 미검수` 유지(확정은 사람).
- 재색인: Chroma 백업 후 4,829청크. RAG 스모크: 복원된 별지(일용직 별지 제1호
  근무시간 항목)가 근거로 인용됨.
- **롤백 경로**: 원본 HWP가 진실원천 — `01_hwp_to_md --overwrite-restored` 재변환으로
  언제든 변환본 상태로 복귀 가능(볼트는 VCS 밖이지만 원본이 남아 있어 안전).

## 5. 수용 기준
- verify-calendar-forms ③ 확장: 기본 30행·10개 전환·페이지 이동·`/forms-pdf/` 다운로드 링크·
  정크 서식명('10일 이내') 부재.
