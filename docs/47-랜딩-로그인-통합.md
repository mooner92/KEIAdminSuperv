# docs/47 — 랜딩·로그인 통합 (소개를 메인으로)

> 2026-07-16. 지시: 소개를 숨길 이유가 없으니 랜딩과 통합. 비로그인 '/'를 로그인 화면이 아니라
> **소개 화면**으로 바꾸고, 로그인 시트는 **같은 위치에 sticky 고정**(스크롤해도 이동 X) —
> 스크롤하면 뒤(옆)에 소개가 주르륵 내려가며 보이게. 디자인은 더 깔끔·명확하게.

## 1. 변경
- 비로그인 `/` 렌더를 **컴팩트 2열(히어로+로그인, 무스크롤)** → **통합 스크롤 랜딩**으로 교체.
  - 왼쪽(`.mergedIntro`): 히어로 + 소개 4섹션(01 질문하기·02 근거·03 둘러보기·04 신뢰)이 스크롤.
  - 오른쪽(`.mergedLogin > .loginSticky`): 로그인 카드 `position: sticky` — 스크롤해도 제자리.
- `/about`(변형 `full`)은 그대로 유지(외부 공유용 로그인 없는 내러티브). 홈의 '서비스 소개 자세히 보기' 링크 제거(소개가 인라인이라 불필요).
- counts를 `index.tsx` getStaticProps → `Assistant` → `Landing(variant="home")`로 전달(수치 스트립·통계 실측).

## 2. sticky 구현의 함정 (수정 기록)
- `position: sticky`가 안 먹던 원인: 그리드에 `align-items: start`를 줘서 **로그인 컬럼이
  콘텐츠 높이로 붕괴** → sticky가 이동할 세로 공간이 없었다.
- 해결: `align-items`를 기본값(stretch)으로 → 로그인 컬럼이 소개 높이만큼 늘어나 sticky가
  헤더 아래(`top: header+20px`)에 고정된 채 소개만 스크롤.
- 실측: 스크롤 700px에도 카드 y 96→76(불변, ✅). 다크·라이트·1900/1440/375 전부 확인.

## 3. "깔끔·명확" 디자인
- 소개 섹션의 **풀블리드 컬러블록(mBlue/mGreen…) 제거** → 테마 배경 + 섹션 상단 **얇은 구분선**만.
- 그라디언트는 히어로 한 줄만, **미드톤(#3182f6→#8b5cf6→#e0508a)** 으로 교체 — 라이트/다크 양쪽 대비 확보(통합 홈은 테마 배경이라 기존 다크 전용 톤은 라이트에서 흐렸음).
- 넘버링 아이브로(01~04)·초대형 타이포(clamp 44~84px)·모노 메타 스트립·라이브 펄스 점 유지.
- 모바일(≤900px): 단일 컬럼, **로그인 먼저**(order:-1) 후 소개, sticky 해제. 375px 가로 스크롤 0.
