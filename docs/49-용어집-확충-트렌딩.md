# docs/49 — 용어집 확충(규정 정의 추출) + 트렌딩 키워드 용어집화

> 2026-07-16. 지시: ① '요즘 많이 찾는 키워드'는 용어집 등재어로만 ② 전체 문서를 순회해
> 행정용어를 다양하게 추가(너무 쉬운 것 제외).

## 1. 트렌딩 키워드 = 용어집 등재어만
- `_trend_lexicon()`(app_api)을 **30_용어집 노트 제목**만으로 재구성(볼트 미접근 시 기존
  여정 트리거+defterms 폴백). '사용' 같은 일반어 유입 구조적 차단 — 칩이 곧 용어집 등재어.
- 렉시콘이 엄격해져 7일 창이 빌 수 있음 → 프론트에서 **7일 비면 30일 폴백**(칩 공백 방지).

## 2. 용어집 확충 — ⛔ 지어내기 금지 원칙의 해법: 규정 정의 조항 인용
전 규정(111개) 순회 추출 2패스:
- 패턴 A: `"X"란 …을 말한다`(제N조 정의 조항) → 66건 후보
- 패턴 B: `(이하 "X"라 한다)`(본문 내 정의 선언) → 82건 후보
사람 큐레이션으로 **31건 확정**(약칭 선언·위원회명·자명어·IT 일반어 제외):
감사(감사인·협동감사제도·감독관청) · 윤리/행동강령(금품등·직무관련자·직무관련임직원·
외부강의등·초과사례금·행동강령책임관·사적이해관계자·이해충돌방지담당관) · 인권/고충
(성희롱·성폭력·직장 내 괴롭힘·인권경영·인권침해행위) · 연구윤리(연구부정행위) · 저작권
(공공누리·2차적저작물·저작재산권·비독점적 이용허락·재이용허락) · 보안/개인정보(비밀·
개인정보 보호책임자·개인정보취급자) · 복무(대체휴일) · 문서(시행문) · 회계/계약(불용품·
수의계약·예산책임자) · 기관(정부출연연구기관).

- **파이프라인**: `tools/01h_defs_to_terms.py`(신규, 재실행 가능) — ALLOWLIST(사람 큐레이션)만
  생성, 정의문은 **원문 그대로 인용**('다음 각 목/호'는 연속 항목까지 수집), 출처 조문
  `[[규정 stem#제N조]]` 위키링크, `검수상태: 미검수`. 출력: `30_용어집/규정정의/`.
- 결과: 용어 88→**119**, 문서 332→**363**, 청크 4,797→**4,829**(Chroma 백업 후 재색인).

## 3. 검증
- 트렌딩 API 키워드 전부 용어집 등재어(실측 ['국내출장']) · verify-trending 5/5(일반어 칩 없음 계약 유지).
- verify-term-tooltip 13/13(119개 로드) · erp-chat 회귀 통과.
- RAG 스모크 "연구부정행위가 뭐야?" → 위조·변조·표절 유형 정의 정상 답변.

## 4. 남김
- 정의 조항 없는 실무 은어(상신·편철 등)는 근거 없는 정의 창작 위험 → 검수자(사람)가
  정의문을 승인하는 방식으로 후속(01h ALLOWLIST에 수동 정의 지원 추가 검토).
- 신규 31건은 전부 미검수 — review_queue 트랙에서 사람 검수.
