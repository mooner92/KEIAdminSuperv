# docs/43 — 업무 캘린더 개편: 이번 달 중심 + 연간 그리드

> 2026-07-16. 사용자 피드백: "딱 봤을 때 캘린더 같은 느낌이 안 나고 정신이 없다."
> docs/40의 카드 나열형을 '이번 달 중심 + 고정 12칸 달력 그리드'로 재설계.

## 1. 문제 진단 (기존 화면)
1. **위계 부재** — 전 항목이 제목+칩+시기+설명+링크 풀세트 카드. 전부 같은 강도라 훑기 불가.
2. **달력다움 부재** — 3열 가변 높이 컬럼이라 연간 구조가 안 보임. 달력은 빈 달도 같은 크기 12칸.
3. **칩 소음** — 거의 전 항목이 `대외업무` 핑크 칩(기본값이면 표시할 정보가 아님).
4. **`관련 문서 →` 20회 반복.**
5. **'지금' 앵커 부재** — 사용자의 실제 질문은 "이번 달 뭐 챙기지"인데 1월부터 나열.

## 2. 새 구조 (위→아래)
| 층 | 내용 | 밀도 |
|---|---|---|
| 🔁 매월 스트립 | 기본 접힘 — 한 줄 인라인 제목 링크(· 구분) + 펼치기 ▾ → 5건 상세 그리드 | 최소 |
| ⭐ 이번 달 히어로 | 유일하게 설명·시기·상태까지 표시. primary 테두리 + '이번 달' 배지 | 최대 |
| 🗓 연간 그리드 | 고정 4×3(균일 높이 `grid-auto-rows:1fr`) 12칸. 큰 월 숫자 + 한 줄 제목 링크만. 빈 달 `—` | 낮음 |

- **칩·설명·'관련 문서→' 그리드에서 전부 제거** — 제목 자체가 문서 링크(`?from=/calendar/` 유지).
- `상태: 예시`는 `⁎` 마크(+툴팁)로 축약, 하단 ⓘ에 범례. 정확성 고지(3개년 관측 통계·규정 아님) 유지.
- 이번 달 계산은 클라이언트(`new Date()`) — 정적 export가 오래 서빙돼도 항상 현재 달.
- 반응형: 1024px 3열 → 760px 2열 → 480px 1열(자동 타임라인화).

## 3. 파일
- `web/pages/calendar.tsx` — 전면 재작성(TitleLink 공용 렌더, everyOpen 토글, hero).
- `web/styles/Calendar.module.css` — 전면 재작성(strip/hero/yearGrid/cell).
- `web/verify-calendar-forms.mjs` — 새 수용 기준(스트립 접힘·펼침 5건·12셀·히어로·'관련 문서→' 0회).

## 4. 수용 기준 (실렌더 16/16 통과)
- 매월 스트립: 접힘 시 인라인 제목 링크 ≥4, 펼치면 li 5건.
- 12개월 셀 정확히 12개(`aria-label="N월 업무"`), 이번 달 히어로 1개 + 배지.
- 문서 링크 ≥15(제목=링크), 본문에 "관련 문서 →" 문자열 0회.
- 다크 월 제목 밝기 > 150 (실측 240).
