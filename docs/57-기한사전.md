# docs/57 — 기한 사전 `/deadlines` (Spec)

> 아이디어풀(docs/38 §A) "기한 사전" 구현 Spec. 서식 찾기(`/forms`, docs/34 ①)와 **동형·모듈식**.
> 목적: 신입이 규정명을 몰라도 **사건→기한→규정**으로 역방향 탐색. 정식 검수·활용 고도화는 후속.

## 1. 왜 (문제)
- 전 규정에 흩어진 **상대기한 228건**(57개 규정)이 드로어(문서별 `DeadlineCalc` 패널)에만 있어, 규정을 이미 알아야 접근 가능.
- 신입에게 "언제까지"는 규정 지식보다 급하다 — "출장 정산 며칠 이내?"를 **규정 몰라도** 한 화면에서 찾게.
- 서식 찾기와 같은 성격(기존 인덱스를 새 화면으로 개봉, 창작 0).

## 2. 데이터원 (이미 존재 — 수작업 0)
- `tools/index/deadlines.json` (01m 생성). 구조: `{ meta, deadlines: { <규정명>: [ Entry ] } }`.
- **Entry**: `{ 조, 의무, anchor, n, unit, dir, type, 원문 }`
  - `anchor`(사건 기준점, 예 "공무출장 후"·"연구연수 복귀 후" — 빈 값 가능)
  - `의무`(제출·보고·신고·작성·신청… 빈 값 가능) · `n`+`unit`(1·개월) · `dir`(이내|전)
  - `type`(마감 213 | 기간한도 15) · `원문`(검증용 규정 문장 그대로)
- 규모: 57규정 · 228건. 단위분포 일134·개월44·년43·주7. dir 이내201·전27.

## 3. 범위 (모듈식 — 서식 찾기와 격리)
신규 페이지·로더·컴포넌트로 **독립 개발**. 기존 드로어 `DeadlineCalc`(Track B, flag `deadline_calc`)는 불변, 계산 헬퍼만 공유.

### 3.1 백엔드/데이터
- `web/lib/vault.ts` `loadDeadlines()`: deadlines.json을 평탄화 → `DeadlineEntry[]`.
  각 항목에 **규정명 + slug**(title→slug 맵, 없으면 null=비클릭) + regNo + Entry 필드.
  정렬: 계산가능(마감·anchor有) 우선 → 규정명 → 조.

### 3.2 UI (`web/pages/deadlines.tsx`) — forms.tsx 패턴 미러
- 좌측 **규정 필터**(체크박스 패싯 + 카운트, 모바일 접힘 토글) — 서식 찾기와 동일 관례.
- 상단 **유형 세그먼트**(전체 / 마감 / 기간한도).
- **검색 1칸**: 사건(anchor)·의무·규정명·원문 부분매칭. 1.2s 디바운스 `track("deadlines_search")`.
- **행**(카드/표): `사건(anchor) · N단위 이내/전까지 · 의무칩 · 규정명(→드로어 링크) · 조` + `📄 원문` + **인라인 계산**(기준일 date input → 마감일 산술 + `📅 .ics`).
- 페이지네이션 10/30/50(서식 찾기와 동일).
- 빈/무결과·면책 문구.

### 3.3 계산 (절대 규칙1 준수)
- 마감일 = 기준일 ± N (순수 산술, `DeadlineCalc.addOffset`). **추측·환각 0**. 원문 문장 항상 병기(검증 가능).
- 헬퍼 `addOffset·downloadIcs·ko·ymd`를 `DeadlineCalc.tsx`에서 export해 재사용(DRY).

### 3.4 진입점 · 플래그
- 플래그 `deadlines_hub`(release, 기본 off, `/admin` 토글) — 서식 찾기와 동형(백엔드 `app_api.py` FLAG_REGISTRY + 프론트 `flags.tsx` FLAG_DEFAULTS).
- **추가 기능 허브(`/now`)** 에 바로가기 카드 1개(⏱ 기한 사전) — 서식 찾기 카드 옆. GNB 신설 없음(과밀 방지).
- 도움말(`/help`)에 링크 1줄(선택).

## 4. 절대 규칙 준수
- ⛔ 규정 내용 창작 0 — 오프셋·원문은 deadlines.json 그대로(01m가 규정 원문에서 추출).
- ⛔ 마감일은 순수 날짜 산술 + 원문 병기. 기준일은 사용자 입력.
- 정적 export 유지(빌드타임 로드) · 무LLM · 기능 플래그.

## 5. 검증

- 데이터 정합: 로드 건수 = 228, 규정 = 57.

## 6. 자동 라벨 (2026-07-22 — 제목 파편 해결)
