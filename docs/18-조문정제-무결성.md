# 18. 조문 정제·무결성 (Track A) — 삭제필터·참조그래프·정의어사전·개정마이닝

## 0. 왜 만들었나 (한 줄)
쌓인 원문을 **다시 정제**해, "이미 삭제된 조문을 근거로 인용"(⛔ 절대 규칙1 위반)하는 사고를 막고,
조문↔조문 준용·인용을 그래프로 세워 검색·탐색을 보강하며, 규정별 정의어를 인덱싱한다.
17번 로드맵의 34개 카탈로그에 **없던 net-new**(조문 효력·조문참조·정의충돌·개정시계열) 축이다.

## 3. rag_core 통합 (`tools/rag_core.py`) — 재임베딩 불필요

- `INDEX_DIR`(기본 `tools/index`), 토글 `RAG_ARTICLE_STATUS`(기본 on)·`RAG_CLAUSE_XREF`(기본 on).
- `_load_index`/`_ensure_article_status`/`_ensure_clause_xref` — 1회 로드·캐시(인덱스 없으면 조용히 비활성).
- **`_overlay_article_status(srcs, blocks)`**: 회수 결과에 `효력`/`최근개정`/`신설`/`삭제일` 메타를 얹고,
  **삭제 조문을 top-k 뒤로 강등** + 컨텍스트 블록 머리에 `⚠ [이 조문은 삭제되어 효력이 없습니다 · 날짜]` 주입
  → LLM이 유효 근거로 오인하지 않게(⛔ 절대 규칙1 방어). `retrieve()`의 회수 직후·그래프 확장 전에 실행.
- **clause_xref 보강**: `graph_expand_regs`(준용/참조 규정 자동첨부) 경로가 청크 메타 `reg_refs`에 더해
  `clause_xref`의 cross 엣지도 병합 → 더 완전한 준용/인용 동반 로드(중복은 dedup).

라이브 확인(dev 9001):
- `국내출장 여비…` → 여비규정 제16조/제9조에 `효력=유효 · 개정2016.12.5` 배지, 별표2/5 자동첨부.
- `임시직 직원의 복무는…` → 임시직운용규칙 회수 + **인사규정 제9조·직제규정 제11조 준용/참조 자동첨부**.

## 5. 그래프와 검색의 관계 (자주 나온 오해 정리)

- **시각 그래프(`/graph`)는 검색에 쓰이지 않는다.** 그건 `01b/01e/01g/01h`가 만든 문서레벨 `[[ ]]` 위키링크를
  `getGraph()`가 노드·링크로 그린 **사람 탐색용** 산출물이다. `retrieve()`는 이 그래프를 읽지 않는다.
- 검색(`retrieve`)은 **밀집(KURE-v1)→(옵션)리랭커** 가 기본이고, 그래프 신호는 **별도 typed 인덱스**로만 얹는다:
  ① 별표 refs(기본 on) ② reg_refs 1홉(`graph_expand_regs`, prod 기본 off) ③ 행위흐름·기안(`graph_expand_actions`, 기본 off).
- 즉 "큰 문서 그래프는 검색에 안 쓴다"는 **맞다**. Track A의 `clause_xref`는 바로 이 지점을 보강한다 —
  조문↔조문 준용/인용을 typed 엣지로 세워 **검색(reg 확장)이 실제로 소비**하게 만든다(위 §3).

## 7. Track C — 그래프 확장 (clause_xref 위에서, **구현 완료 dev**)

`clause_xref.json` 위에서 `tools/01l_graph_analytics.py`가 3개 분석을 산출한다 →
`tools/index/graph_analytics.json`(재파싱·재임베딩 없음):
- **개정 파급(impact)** — 규정 A의 조문이 B를 준용/참조하면 A는 B에 의존. B 개정 시 영향 = B를 (전이적으로)
  참조하는 규정 = **역방향 전이폐포**(reverse BFS, 최대 3홉). 실측 파장 top: **복무규정 24 · 인사규정 21**.
- **함께 보는 조문(cocitation)** — 같은 조문에서 함께 인용된 조문 쌍(공동인용) 빈도 → 조문별 이웃(217조문).
- **고립 노드(isolated)** — cross 엣지(in·out) 없는 규정 = 그래프 사각지대(autolink 보강 후보). 실측 45개.

웹(플래그 `graph_impact`): 빌드타임 `emit-docdata`가 규정별 `trackC` 슬라이스(개정 파급·함께 보는 조문, **규정명→slug 해석**해 클릭 이동)를 부착 → 문서 드로어에 "개정 파급 — 이 규정을 준용·참조하는 규정 N(전이 홉 표시)"·"함께 보는 조문" 패널. 고립 진단은 빌드 리포트/JSON.
검증: `verify-trackC.mjs`(파급·공동인용 렌더 + 파급 칩 클릭→대상 규정 로드, 404 아님) 5/5.

**다음(미착수)**: 다홉 경로찾기(ACTION_FLOWS 확장) · 고립노드 진단 admin UI · 트랙 D(로그 기반 신뢰 루프).
