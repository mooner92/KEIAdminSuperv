## ② 신뢰 운영 트랙 (flag `trust_ops`, /admin 🛡 신뢰 탭) — 검수의 조준경

**데이터 실측 전제(2026-07-14)**: assistant 메시지 208건 전부 근거 JSON 보유(필드: 규정명·조·
slug·type·distance…, **검수상태 없음**) → 검수상태는 **볼트 프론트매터를 런타임 조인**(5분 캐시).
이 의미론이 옳다: 문서가 검수완료로 승격되면 과거 답변도 자동으로 위험 목록에서 빠진다.

`GET /app/trust?days=30` (current_admin) — 응답 3블록, **본문·질문 텍스트 0**:

1. **고위험 답변 레이더**: 기간 내 assistant 메시지 중 ⓐ 본문에 금액 토큰 존재(서버에서 검사만,
   반환 안 함) ⓑ 근거 중 미검수 문서 인용 — 를 만족하는 건의 집계 목록.
   행 = `{at, 근거: [{규정명, 조, 검수상태}], money: true, n_unreviewed}` (메시지 id·본문 없음).
   정렬 = 최신순, 상한 50. 목적: "돈 얘기를 미검수 근거로 답한 사례"를 검수 우선순위로 직결.
2. **수요×품질 매트릭스**: 규정 단위 집계 — `{규정명, 인용수(수요), 검수상태(품질), down수}` →
   프런트가 "인용 많음×미검수" 사분면을 강조 정렬. 규정 단위라 k-익명 불요(개인 정보 없음).
3. **👎 오류유형 분류**: Feedback(down) 사유를 결정적 키워드 버킷(금액·기한·출처·낡음·누락·기타)으로
   집계 `{유형, n}` + 최근 사유 원문 목록(피드백 사유는 사용자가 신고용으로 쓴 텍스트 —
   기존 /app/feedback도 반환하므로 노출 범위 동일).

UI: /admin 탭 `🛡 신뢰`(flag `trust_ops`) — 레이더 표·매트릭스 표(미검수·다인용 상단)·유형 칩.
각 행에서 규정명 클릭 → /d/문서. 수용: ⓐ 본문·질문 문자열이 응답에 없음(자동 검사)
ⓑ 검수완료 문서는 레이더·매트릭스 '미검수' 축에서 제외 ⓒ flag off 시 탭 미노출 ⓓ 다크 실측.

## ① 서식 찾기 (flag `forms_registry`, /forms) — 수작업 0으로 시작

**데이터 실측 전제**: 규정원문 64문서에 `[별지 제N호 서식]` 라벨(줄 시작) + 다음 줄 = 서식명
(예: 복무규정 별지 제1호 → "연구사업이행각서"). 본문 중 인용("별지 제1호서식의…")은 줄 시작이
아니므로 자연 제외.

- **빌드타임 추출**(emit-docdata.mts): 규정집 문서 본문에서 줄 시작 별지 라벨 스캔 →
  `out/forms.json` = `[{규정명, slug, 호수, 서식명, anchor("별지 제N호")}]`.
  별표(기준표)는 v1 범위 제외(서식이 아님 — 필요 시 후속).
- **/forms 페이지**: 검색 1칸(서식명·규정명·번호 통합, "별지 3"·"출장" 류 질의 지원) + 표
  (서식명 | 규정명 | 별지 번호 | 바로보기→ 문서 앵커). 정적 SSG(getStaticProps) + flag 게이트
  (off = 준비 중 안내, journey 관례). GNB엔 넣지 않고 **둘러보기 옆이 아닌 푸터 + 도움말 허브 +
  changelog 노트**로 진입(메뉴 과밀 방지 — 반응 보고 GNB 승격).
- 수용: ⓐ forms.json 건수>0·필드 완전성 ⓑ 검색(번호·이름·규정명) 실렌더 ⓒ 바로보기 → 문서
  해당 별지 앵커 착지 ⓓ flag off 미노출 ⓔ 다크 실측.
- 후속(별도): 양식함 41건 CSV(사람) 수집 시 "전자결재 가능" 열 추가.

## ③ Quick wins

1. **/admin 대시보드 기간 필터**: 일(1)/주(7)/월(30) 셀렉터 → `api.stats(days)` 재호출(백엔드
   `?days=` 기존). 수용: 전환 시 수치 변화 실렌더.
2. **채팅 Stop 버튼 + 2단계 대기 표시**: 스트리밍 중 [보내기]→[■ 중단]으로 전환.
   중단 = 클라이언트 스트림 종료(서버는 백그라운드 완료·저장 — 재입장 시 전체 답 보임을
   말풍선에 "(중단됨 — 다시 열면 전체 답변이 보여요)"로 정직하게 표기). 대기 표시 =
   meta(근거) 수신 전 "규정 검색 중…" → 첫 delta 전 "답변 작성 중…". 수용: 중단 즉시 입력
   가능 + 표기 노출 + 새로고침 후 전체 답변 표시(실렌더).
3. **judge 프롬프트 오판 2건**: (후속 유지 — 골든셋 judge 재실행 비용 대비 이득 낮아 이번
   묶음에서 제외, 기록만.)
