# QualityDigest — 일일 자가평가 결과

**감지**: `eval/daily_run.sh` 완료(03:00 cron · 주말은 03·11·19시 3회). 매일 1~3건. ⚪ SEV3 — **조치 불필요**.

> 2026-08-03부터 메시지 끝에 `· 어휘갭 N%p · 🔧수술대기 N건`이 붙는다(daily_report 산출). 수술 대기 = 검색실패·생성환각(고칠 것), 측정 노이즈(시험지 문제)는 제외된 수다.
목적: 품질 게시판을 매일 열지 않으니 숫자만 밀어 준다.

## 숫자를 읽는 법
```
전체 88.1% · 재시험 80.0%(20건) · 신규 92.3%(40건)
```
- **전체 정답률의 일별 비교는 대부분 표본 구성이다.** 문항의 ~85%가 매일 교체된다(docs/58 §6d).
- **재시험 코호트**(전에 틀려 다시 물은 문항)만이 개선·회귀를 증명한다. 여기만 본다.
- 정답률 = 정답 / (전체 − 판정불가 − 폐기). 분모가 작으면 %가 크게 흔들린다 — 건수를 함께 본다.

## 볼 곳
품질 게시판(`/quality`) — 실패유형별 분포가 다음에 고칠 것의 우선순위다.

| 실패유형 | 뜻 |
|---|---|
| `검색실패` | 근거를 못 찾았다 — 검색 트랙 |
| `생성환각` | 근거는 맞는데 답이 틀렸다 — 프롬프트·모델 |
| `골든품질`·`출제결함` | **채점이 불가능한 문항** — 고쳐도 점수가 안 오른다. 골든셋 보수 대상 |
| `미분류` | ⛔ **분류기에 구멍이 있다는 신호.** 알려진 판정값이 여기 떨어지면 버그다 |

## 알림이 안 오면
cron이 돌지 않았거나 GPU 가드(21000 MiB)에 걸려 스킵됐다. `eval/daily/` 최신 파일 날짜를 확인한다.
