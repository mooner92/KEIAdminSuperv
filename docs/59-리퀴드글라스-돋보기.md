# docs/59 — 리퀴드글라스 돋보기 (Reader Glass)

> 조밀한 규정 본문을 커서 위치에서 확대해 읽는 유리 렌즈(flag `reader_glass`).
> 참고: kube.io/blog/liquid-glass-css-svg (SVG feDisplacementMap 리퀴드글라스).

## 구조 (web/components/reader/)
- **실제 확대(전 브라우저)**: 대상 `<article>`의 outerHTML을 렌즈 안에 복제 → 커서의
  article-local 좌표 (px,py)를 `translate(RX−Z·px, RY−Z·py) scale(Z)`로 렌즈 중앙에 매핑.
  복제본은 읽기 전용(링크·버튼 pointer-events 차단), 렌즈 자체도 pointer-events:none
  (아래 본문 hover·선택 유지). Esc/토글로 종료.
- **리퀴드 굴절(Chrome 전용, 우아한 폴백)**: 타원 정규화 거리 기반 변위맵(canvas 1회 생성,
  rim 바깥 22%만 smootherstep 굴절)을 `feImage`+`feDisplacementMap`으로 구성,
  `backdrop-filter: url(#…)`는 Chrome만 지원 — `CSS.supports` 감지, 미지원 브라우저는
  CSS 글라스(광택·rim 링·그림자)만으로 자연스럽게 동작.
- **형태**: 다이나믹 아일랜드형 가로 필(RX150×RY68, border-radius 999px) — 조문은
  '한 줄'을 넓게 읽는 게 유용(사용자 확정). ZOOM 1.9.
- 진입: 문서 페이지(/d/*) 우하단 플로팅 토글(`ReaderGlassToggle`, flag 게이트 내장).
  규정 둘러보기→문서로 이동 시 커버. 채팅 근거 드로어(DocDrawer) 통합은 후속.

## 검증
`web/verify-glass.mjs`(4/4): 토글 노출·렌즈 표시·확대 본문 복제·본문 밖 숨김.
실렌더 스크린샷(라이트·다크) — 제5조 확대 가독 확인.

## SVG 필터 추가 적용 후보(제안 — 튀지 않는 선)
- 근거 바텀시트/모바일 탭바 배경: 표준 blur 글라스(backdrop-filter: blur+saturate —
  전 브라우저) + 아주 약한 rim. 굴절(feDisplacementMap)은 Chrome 한정이라 장식 층으로만.
- 용어 툴팁 팝오버 배경 글라스화(blur 6px) — 본문 위에 뜨는 요소라 자연스러움.
- 랜딩 히어로 통계 카드 rim 하이라이트(정적 CSS만).
⛔ 본문·표·근거 카드 등 '읽는 면'에는 굴절/블러 금지(가독 우선).
