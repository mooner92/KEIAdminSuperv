# 21. 관리자 페이지 UX 개편 — 스펙 (v1.1)

> 배경(사용자 요청, 2026-07-09): ① 코퍼스 목록이 단순 나열이라 보기 어려움 — 규정 둘러보기처럼.
> ② "제외"가 삭제로 오해될 수 있음 — **제외 문서함**으로 분리·명시. ③ 기능 플래그 카드가 과대·필터 없음.
> ④ 기능이 늘어날 관리자 페이지를 **탭 구조**로(메인 GNB처럼) — 확장 가능하게.

## 1. 탭 구조 (admin.tsx)
- 상단 탭 바: **📊 대시보드 · 📚 코퍼스 관리 · 🚩 기능 플래그** (신규 기능은 탭 추가로 확장)
- 탭 상태는 URL 해시(`#corpus` 등)와 동기화 — 새로고침·딥링크 유지. 기본 = 대시보드.
- 대시보드 탭 = 기존 운영 대시보드 + 👎 피드백 사유. 플래그 탭 = 플래그 관리 + 변경 이력(감사).
- 코드 분리: `components/AdminCorpus.tsx` · `components/AdminFlags.tsx`(admin.tsx는 탭 셸만).

## 2. 코퍼스 관리 탭 — 둘러보기(Explorer)형
- **레이아웃**: 좌측 체크박스 필터(Explorer.module.css 재사용 — 디자인 통일) + 우측 목록.
  - 필터 그룹: **구분**(업무가이드/규정원문/용어집/시스템 — 볼트 상위 폴더) · **분류**(하위 폴더) ·
    **검수상태** · **색인 상태**(정상/재색인 필요). 패싯 카운트 + 초기화.
  - 백엔드 `GET /app/corpus`에 `구분` 필드 추가(상위 폴더), `section`은 분류(하위 폴더) 유지.
- **목록**: 검색 + 페이지네이션(30/쪽, Explorer 페이저) — 기존 "60건 제한" 제거.
- **⛔ 제외 문서함 분리**: 서브뷰 토글 `[전체 목록] [🗂 제외 문서함 N]`
  - **전체 목록에는 제외 문서를 표시하지 않는다**(현재 코퍼스만) — 제외=이동으로 인지되게.
  - 제외 문서함: 붉은 "제외됨" 배지 + 안내문 "**파일은 삭제되지 않았습니다** — 색인에서만 빠지며 복귀 가능"
    + 행별 [복귀] 버튼. 복귀 시 전체 목록으로 돌아가고 ⟳ 재색인 필요.
- 업로드·재색인·롤백 UI(P2·P3)는 코퍼스 탭 상단에 유지.

## 3. 기능 플래그 탭 — 컴팩트
- **행 컴팩트화**: 1행 = 토글 + key + 만료 배지 + 설명 **1줄 요약(말줄임)**. 행 클릭 시 설명 전체 펼침(아코디언).
- **검색/필터**: 키·설명 검색 입력 + 상태 칩(전체 / ON / OFF / 만료 임박·초과).
- 변경 이력(감사)은 플래그 탭 하단 접이식.

## 4. 수용 기준
ⓐ 탭 전환·해시 딥링크(#corpus 새로고침 유지) ⓑ 코퍼스: 필터 패싯·페이지네이션·검색 동작
ⓒ 제외 토글 → 전체 목록에서 사라지고 제외 문서함에 "제외됨"+복귀 버튼으로 표시, 복귀 시 원상
ⓓ 플래그: 검색·상태 필터·1줄 요약↔펼침 ⓔ Playwright 실렌더(관리자 계정)
