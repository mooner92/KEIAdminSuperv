## 1. 업무 캘린더 페이지 분리 (/calendar)
- 신규 `pages/calendar.tsx`(flag events_tab) — GNB '업무 캘린더' 탭. 12개월 그리드 + **매월(상시)
  블록을 상단에 항상 펼친 상태로**(접힘 제거). 이번 달 카드 강조(테두리+배지). 대외업무 구분 칩·
  관련 문서 링크·통계 고지. `track("calendar_view")`(TRACK_EVENTS·프리픽스 추가).
- /now 캘린더 카드는 **컴팩트 요약**으로 축소: 이번 달(없으면 매월) 상위 4건 + "📅 업무 캘린더
  전체 보기 →" 링크. 월 칩·매월 details·다음달 미리보기는 /calendar로 이전 → /now 카드 높이 균일화.

## 2. 서식 찾기 필터 (/forms)
- 좌측 규정 필터 패널(규정 둘러보기 패턴): 규정명 체크박스 + 서식 수 패싯 카운트(검색 결과 기준
  동적) + 패널 내 규정 검색 + 초기화. 2열 레이아웃(≤760px 1열). 서식명·번호 통합 검색은 유지.
