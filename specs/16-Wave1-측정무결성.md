## W1-C (P1) — 거부 판정의 노트 오염 수리

**현재**: `tools/refusal_detect.py:38-40` — 첫 문단 <40자면 `t[:200]` 폴백. 노트는 `\n\n`
뒤에 붙으므로 짧은 답변에서 노트가 스캔 범위에 든다. `numeric_guard_note` 문구
"확인되지 않았습니다"(rag_core:888)가 `REFUSAL_RE`의 `확인되지\s*않`과 매치 —
**정상 답변이 거부로 오채점**되는 실증 경로(T9와 같은 계열).

**변경**:
1. `refusal_detect`에 **노트 마커 레지스트리** 신설(이 모듈이 정본 — rag_core를 임포트하지
   않아 순환 없음):
   ```python
   NOTE_MARKERS = ("⚠️ **", "ℹ️ ")   # 시스템이 덧붙이는 노트 문단의 시작 서명
   ```
2. `_head()` 전에 **꼬리 노트 문단 제거**: 끝에서부터, 문단이 NOTE_MARKERS로 시작하거나
   면책 핵심 어구("최종 판단은")로 시작하면 제거. **끝에서만** 제거한다 — 모델이 본문
   서두에 자체적으로 ⚠️를 쓰는 경우(결론일 수 있음)는 건드리지 않는다.
3. **문구 계약**: "모든 시스템 노트는 NOTE_MARKERS 중 하나로 시작한다"를 rag_core 소스
   스캔 회귀로 고정 — 신설 노트가 자동으로 규약을 따르게(향후 T1 배지 전환 시에도 안전).

**회귀**(`tools/test_refusal_detect.py` 확장):
- 짧은 정답 + 수치 노트 → 거부 아님(**수정 전 실패를 먼저 확인**)
- 짧은 진짜 거부 + 노트 → 여전히 거부
- 노트만 있고 본문 없음 → 거부 아님
- rag_core 노트 리터럴이 전부 NOTE_MARKERS로 시작(소스 스캔)

**면책 최후행(⚠ 범위 축소)**: 비스트림은 노트를 면책 앞에 삽입 가능하나 SSE는 이미 방출된
텍스트를 회수할 수 없어 물리적으로 불가. **이번 Wave 보류** — W1-C 1~3으로 실해(거부
오염)는 제거되고, 순서는 순수 표기 문제라 Wave 3에서 재검토.

## W1-E (P0+) — x_gates 요약 + 인용 대조 카운터 (T1의 텔레메트리형 흡수)

**무엇**: 순수 함수 `rag_core.gate_summary(answer, context, srcs) -> dict`:
```python
{"routes": {"defterm_route": 1, ...},   # srcs의 truthy 라우트 플래그 집계
 "절단": bool,
 "cite_total": n,                        # 답변 내 [ … 제N조|별표N ] 인용 수
 "cite_unmatched": m,                    # 컨텍스트+태그에서 못 찾은 인용 수
 "cite_unmatched_list": [...]}           # ≤5, 관리자 확인용 — 답변에는 아무것도 안 붙임
```
**인용 대조 규칙(T1 감사 반영 — 오탐 회피가 설계의 절반)**:
- 허용집합은 `x_sources`가 아니라 **컨텍스트 텍스트 + srcs 태그**에서 수확(공백 제거 정규화).
  → FP-B(조문 상호참조 854건)·FP-C(impact 목록) 오탐 제거. 8/7 실표적("개인정보 보호법
  제25조제1항" — 컨텍스트에 규정명 자체가 없음)은 그대로 잡힘.
- 규정명·조를 **각각** 확인(둘 다 있어야 matched). `제N조의M` 보존, `별표 N`/`별표N` 공백
  무시. 정규화는 공백 제거(`_tighten_spacing`이 QWEN35 전용이므로 입력 공백 의존 금지).
- **FP-A(멀티턴 이전 인용) 한계 명시**: history 미전달로 이전 턴 인용은 unmatched로 셀 수
  있음 — 해석 시 멀티턴 비율과 함께 볼 것(배지가 아니므로 사용자 피해 0).

**배선**(응답 필드만 — 답변 텍스트 불변·DB 스키마 불변):
- `tools/04_rag_api.py` `/v1` 응답에 `"x_gates"` 추가(`x_sources` 옆).
- `tools/app_api.py` 비스트림 응답 + SSE **done 이벤트 payload**에 추가(스트림 본문 불변).
- 관리자 집계: 신규 `GET /app/gates`(current_admin) — 최근 14일 assistant 메시지의
  `sources_json`(플래그 포함 저장 확인됨 — `app_api.py:2871,2901`)에서 라우트 발동 집계 +
  총 메시지 수. 본문·질문 미반환(개인정보 원칙 유지).

**회귀**(`tools/test_gate_summary.py` 신규, 합성만):
