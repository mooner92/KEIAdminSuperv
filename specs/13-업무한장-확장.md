# Spec 13 — 업무 한 장 확장: "그림"에서 "일하는 화면"으로

> 2026-08-03 · 운영자: "업무 한 장 이거 평이 되게 좋은데, 여기에 추가할 수 있는 작업이 있으면
> 계획 잡아줘." 관련: docs/25(업무 한 장 정본) · docs/17 Track B(기한·결재선) · specs/12.

## 0. 현황 실측 — 좋은 평가를 받는 이유와, 그래서 아쉬운 것

여정 13종 · 노드 67개. 노드가 가진 것을 세어 보면:

| 필드 | 채워진 노드 | 비고 |
|---|---|---|
| `근거`(규정명·조) | **67/67** | 이게 이 화면이 신뢰받는 이유 — 모든 단계에 원문 링크.
  ⚠ 단 근거 122건의 내역은 규정 조문 47 · 별표 16 · **ERP·가이드 문서 59**다(2026-08-03 실측) |
| `erp`(메뉴 경로) | 20/67 | |
| `전결` | **8/67** | 그런데 `approval.json`엔 **335규칙**이 있다 |
| `기한` | **7/67** | 그런데 `deadlines.json`이 이미 원문 기한을 갖고 있다 |
| `서식` | **0/67** | 서식 찾기엔 별지 PDF가 다 있는데 **연결이 없다** |

즉 이 화면의 문제는 품질이 아니라 **고립**이다. 프로젝트가 이미 결정적으로 뽑아 둔
인덱스(기한·결재선·서식·조문 효력)와 손으로 만든 여정이 서로 모르는 상태다.
사람이 "그래서 지금 뭘 내야 하지?"를 알려면 다른 화면으로 나가야 한다.

## 1. 방향 — 여정을 인덱스에 접붙인다(창작 없음)

⛔ 여정 노드는 계속 **사람이 큐레이션**한다(docs/25 원칙). 자동화하는 것은 큐레이션이 아니라
**연결**이다. 붙는 값은 전부 기존 인덱스에서 오고 근거 조문을 달고 온다 — 지어내지 않는다.

## 2. 작업 (효과 큰 순서)

### A. 여정 ↔ 인덱스 접붙이기 (`tools/01r_journey_enrich.py`, 결정적·LLM 0회)
노드의 `근거`(규정명·조)를 키로 자동 보강:
- `deadlines.json` → 그 조문에 기한이 있으면 `기한` 후보 부착(7/67의 공백)
- `approval.json` → 그 업무의 전결 규칙 연결(8/67의 공백)
- 서식 manifest → 그 단계에서 내는 서류(별지) 후보
- ⛔ **자동 확정 금지** — 전부 `제안` 필드로 넣고 사람이 확인해 승격(볼트는 미검수로 시작).

### B. 신선도 감시 — 수작업 큐레이션의 최대 약점
여정은 손으로 만들어서 **규정이 개정되면 조용히 낡는다**. 노드 근거를 `article_status.json`과
대조: ⓐ 삭제 조문 → 여정 상단 ⚠ + 검수 큐 최우선 ⓑ 최근 개정 → "개정됨" 표시.
재색인 후 크론에서 결정적으로 돌린다.
**A보다 급할 수 있다** — 틀린 안내는 없는 안내보다 나쁜데, 지금은 낡았는지 알 방법이 없다.

### C. 단계 체크(내 진행 상태)
"신청까지 했고 정산이 남았다"를 화면이 기억한다. 1차 localStorage(서버 변경 0), 반응이 좋으면
app.db 승격(기기 간 동기화). 진행률 + "다음 할 일" 한 줄.
⚠ 개인정보 최소 — 무엇을 언제 체크했는지만, 내용 없음.

### D. 기한 계산기 인라인
드로어에만 있는 `deadline_calc`를 여정 단계에 붙인다: 기준일(출장 종료일 등) 입력 →
남은 일수·마감일·.ics. A가 기한을 채워야 의미가 있으므로 A 다음.

### E. 다음 여정을 데이터로 고르기
지금 13종은 감으로 골랐다. 이제 근거가 있다 — k-익명 인기·거부 질문 통계 + **검색실패가
몰린 규정**(specs/12 1단 분석서가 매일 계산) → "여정이 없어서 헤매는 업무"를 후보로.
분기마다 3종씩 추가.

### F. 채팅 → 여정 딥링크
답변에서 주제가 감지되면 해당 **단계로** 이동(현재는 결재선 카드만 있다).
"출장 정산" 질문 → 국내출장 여정의 정산 단계.

## 3. 하지 않을 것

- 여정 노드 자동 생성(LLM) — 이 화면의 가치는 사람이 확인한 정확성이다. 초안도 만들지 않는다.
  (연결은 결정적으로, 큐레이션은 사람이.)
- 결재 상신·ERP 쓰기 연동 — 우리는 안내지 업무 시스템이 아니다.
- 개인 업무 데이터의 서버 저장 확대(C 이상) — 필요가 증명되기 전에는.
