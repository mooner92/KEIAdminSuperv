# Spec 09 — 호롱 실험실(Lab): 실험 기능 상설 무대 + 첫 입주 '코드 그래프'

> 2026-07-31 · 운영자 지시: "그래프 보여주는것도 horong에서 실험실 이런식으로 하나 운영해서
> 거기서 그래프도 보여주고 그러지 뭐." 관련: docs/13(기능 플래그) · docs/44(로그인 게이트) ·
> docs/66(알림 정책 — 게이트 규약 동형) · scripts/graphify-refresh.sh(그래프 생성·유출 검사).

## 0. 배경 — 왜 '실험실'이라는 그릇인가

graphify 코드 그래프(4,114 노드·342 커뮤니티, 2026-07-31 실측)를 운영자만 로컬 파일로 보고
있다. 보여줄 곳이 없어서다. 그런데 이런 물건이 이번이 처음이 아니고 마지막도 아니다 —
품질 게시판도, 결재선 판정기도 처음엔 "정식 기능인지 확신 없는 실험"으로 시작했다.

지금까지는 실험을 바로 정식 메뉴에 넣거나(리스크) 안 보여주거나(사장) 둘뿐이었다.
**실험실은 세 번째 선택지다**: 정식 승격 전의 기능을 기대치를 낮춘 무대에 올려 실사용
반응을 얻는다. 인프라는 전부 있다 — 기능 플래그(런타임 토글), 로그인 게이트(내부 전용),
의견함(피드백 수집). 실험실은 이 셋을 묶는 **관례 + 페이지 하나**다.

## 1. 목표 / 비목표

**목표**
- G1. `/lab` 페이지 — 실험 기능 카드 허브. 실험마다 "무엇·왜·상태·피드백 경로" 명시
- G2. 첫 입주: **코드 그래프**(graphify `graph.html`) — 사내망에서 접근 가능하게
- G3. **실험 수명주기 규약** — 실험은 반드시 '졸업(정식 메뉴)' 또는 '퇴출(제거)'로 끝난다.
      기한 없는 실험 금지(FLAG_REGISTRY의 flag debt 규약과 동일 사상)
- G4. 기존 안전 계약 무손상 — 로그인 게이트 뒤·외부 의존 0·유출 검사 통과분만 게시

**비목표**
- 외부 공개(⛔절대규칙 5 — 실험실도 예외 아님. 랜딩 셸(`/`·`/about`)에 노출하지 않는다)
- 그래프 편집·사용자별 그래프(읽기 전용 뷰만)
- 일반 사용자 대상 실험 강제 노출(기본 off — 켜는 건 관리자가 `/admin`에서)
- 볼트(규정) 그래프와의 통합 — `/graph`(규정 관계)와 코드 그래프는 **다른 물건**이다.
  섞으면 사용자가 "규정 그래프에 코드가 왜 나오지"가 된다. 실험실은 코드 그래프만.

## 2. 설계

### 2.1 정보 구조 — 어디에 어떻게 놓나

```
/now (추가 기능 허브, 기존)
 └─ 카드 "🧪 실험실" (flag lab_hub on일 때만 노출)
     └─ /lab — 실험 카드 목록 (PageHero + 카드 그리드, 공용 컴포넌트만)
         └─ 카드 "코드 그래프" (flag lab_code_graph)
             └─ /lab/code-graph — iframe 임베드 + 새 탭 링크 + 기준 커밋·날짜 표기
```

- 진입은 `/now` 카드 하나만. GNB에 탭을 늘리지 않는다(호롱 GNB 3탭 원칙 유지).
- 실험 카드 필수 필드: **이름 · 한 줄 설명 · 시작일 · 졸업 기준 · 피드백 링크(의견함)**.
  졸업 기준이 안 써지는 실험은 실험이 아니라 낙서다 — 카드 등록 자체를 막는다(§2.5 게이트).

### 2.2 플래그 (docs/13 관례 — 코드 레지스트리 = 단일 출처)

| 키 | 기본 | 뜻 |
|---|---|---|
| `lab_hub` | off | 실험실 전체 노출(/now 카드 + /lab 접근) |
| `lab_code_graph` | off | 코드 그래프 실험 카드 + /lab/code-graph |

- 실험 1개 = 플래그 1개. 허브 플래그와 독립(허브만 켜고 실험은 골라 켠다).
- 졸업·퇴출 시 플래그 제거(만료일 명시 — flag debt 금지). FLAG_REGISTRY 주석에
  이 spec 번호를 남긴다.

### 2.3 코드 그래프 서빙 — ⚠ 이 절이 이 spec의 기술적 전부다

`graph.html`은 2MB 단일 파일이고 **graphify-out/은 gitignore**다(코드 구조를 공개 레포에
안 남기는 원칙). 즉 Next.js 빌드(out/)에 못 들어가고, 들어가서도 안 된다. 따라서:

- **server.js 직서빙**: `GET /lab-assets/code-graph.html` → 서버 디스크의 게시본을 읽어
  응답. 선례 = 별지 PDF(`web/public/forms-pdf/` 직서빙, "web 재빌드 불필요").
  ⛔ **로그인 게이트 필수**: server.js의 콘텐츠 차단 목록에 `/lab-assets/`를 넣는다
  (fail-closed — 비로그인은 차단. docs/44 규약, 회귀는 verify-gate-bypass.mjs에 케이스 추가).
- **게시본 분리**: 서빙 대상은 `graphify-out/graph.html`(작업본)이 아니라
  `web/lab-assets/code-graph.html`(게시본, gitignore). 복사는 사람이
  `scripts/graphify-refresh.sh --publish`로만 한다(§2.4). 작업본을 직접 물리면
  갱신 중간 상태·유출 검사 전 상태가 노출될 수 있다.

**⚠ CDN 의존 제거(필수)**: graph.html은 vis-network를 unpkg.com에서 로드한다(실측).
사내망 클라이언트가 외부 CDN에 접근 가능하다는 보장이 없고, 가능하더라도 사내 화면이
외부 CDN에 의존하는 것 자체가 관례 위반(외부 UI 라이브러리 0·self-host 원칙 — Pretendard도
self-host다). `--publish`가 복사할 때 **vis-network를 로컬 사본으로 치환**한다:
`<script src="https://unpkg.com/vis-network@…">` → `/lab-assets/vis-network.min.js`
(venv의 graphify 패키지에 동봉돼 있으면 그걸, 없으면 1회 다운로드해 고정 —
vis-network는 Apache-2.0/MIT 듀얼이라 self-host 문제 없음). 치환 실패 시 게시 중단
(외부 의존이 남은 채 게시 금지).

### 2.4 갱신 워크플로 — 기존 스크립트 확장

```
scripts/graphify-refresh.sh --publish
  = update → cluster-only(이름 유지) → ⛔유출 검사 → CDN 치환 → web/lab-assets/ 복사
    → 게시 메타 JSON 기록 (예: {"commit":"4daa5e1","generated":"2026-07-31"})
```

- 유출 검사(볼트 경로 + 내용어)를 **통과한 산출물만** 게시본이 된다. 검사는 이미
  스크립트에 있다 — `--publish`는 그 뒤에 복사 단계를 더할 뿐.
- `/lab/code-graph` 페이지는 게시 메타 JSON을 읽어 "그래프 기준: <커밋 짧은해시> ·
  <날짜>"를 표기한다(규정집 기준일 `CORPUS_AS_OF`와 같은 정직성 장치 — 썩은 그래프를
  최신인 척 보여주지 않는다).
- 자동 갱신(cron)은 v1 비목표 — 갱신 비용이 명령 하나고, 코드 그래프의 신선도는
  일 단위면 충분하다.

### 2.5 실험 등록 게이트 (docs/66 §2와 동형 — 4문항)

새 실험을 실험실에 올리기 전 4문항. 하나라도 "아니오"면 올리지 않는다:

1. **졸업 기준을 한 문장으로 쓸 수 있는가?** (예: "주간 사용 N명 이상이면 정식 메뉴로")
2. **퇴출 시 흔적 없이 제거 가능한가?** (플래그+카드+에셋만 지우면 끝나는 구조인가)
3. **로그인 게이트 뒤에 있는가?** (내부 전용 — 랜딩 셸 노출 금지)
4. **외부 의존이 0인가?** (CDN·외부 API·외부 폰트 금지)

### 2.6 UI (호롱 디자인 규약)

- `/lab`: `PageHero`(제목 "실험실 🧪" + "정식 기능이 되기 전의 시제품들") + 카드 그리드.
  `/now` 카드 컴포넌트 재사용(신규 CSS 사본 금지 — BrowseUI 통일 관례).
- 실험 카드에 배지: "🧪 실험 중 — 언제든 바뀌거나 사라질 수 있어요".
  기대치 관리가 실험실의 존재 이유다('검수 전 초안' 배지와 같은 정직성 장치).
- `/lab/code-graph`: 상단 안내(이게 뭔지 2줄 + 기준 커밋·날짜) + iframe(전체 높이) +
  "새 탭에서 크게 보기". 다크모드: graph.html 내부는 라이트 고정(graphify 산출물) —
  주변 셸만 토큰을 따르고, 그래프 내부 다크는 v1 비목표.
